# Forzazinho

Projeto de jogo de corrida desenvolvido em C++ utilizando Raylib.

## Funcionalidades

- Movimentação baseada em física
- Rotação do carro
- Sistema offroad
- Modularização em múltiplos arquivos
- Programação orientada a objetos

## Tecnologias

- C++
- Raylib
- Git/GitHub

## Compilação

```bash
g++ main.cpp player.cpp track.cpp -o jogo -lraylib -lopengl32 -lgdi32 -lwinmm
