# Forzazinho

Projeto de jogo de corrida desenvolvido em C++ utilizando Raylib.

## Funcionalidades

- Movimentação baseada em física
- Rotação do carro
- Sistema offroad
- Modularização em múltiplos arquivos
- Programação orientada a objetos

## Tecnologias

- C++
- Raylib
- Git/GitHub

## Compilação

```bash
mingw32-make
```

## Executar o jogo

```bash
mingw32-make run
```

## Recompilar tudo

```bash
mingw32-make rebuild
```

## Limpar arquivos compilados

```bash
mingw32-make clean
```
